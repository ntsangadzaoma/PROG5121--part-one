# Programming 1A POE - Part 1

This project implements the registration and login feature.

The application is a console application.

## Features

- Username validation
- Password complexity validation
- South African cellphone number validation
- User registration messages
- Login validation
- Login success and error messages
- JUnit unit tests

## Main Classes

`Login.java` contains the validation and login methods.

`Main.java` runs the console application.

`LoginTest.java` contains the unit tests.
